## O que é este workflow

Processo de registro estruturado de sessões de trabalho intensivo — especialmente
sessões no Claude que resultem em decisões de design, implementações no ecossistema,
criação de novos instrumentos ou marcos de evolução.

Distinto do W02 (registro de reunião): uma sessão de trabalho tem estrutura diferente
de uma reunião. Não tem pauta formal nem participantes múltiplos — tem problema
inicial, exploração, decisões de design, implementações, erros, correções e aprendizados.
